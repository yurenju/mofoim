# 用詞庫加 n-gram 語言模型猜句子，不用神經網路模型

引擎必須完全離線、資源用量合理，而且要能在 Windows 輸入法 DLL 裡每次按鍵都即時算完。我們決定用詞庫加 bigram 語言模型，把所有可能的解讀排成一張圖後找出總分最高的路徑；「替一串候選字詞評分」切成獨立介面，之後可以替換或疊加其他評分方式。

## Considered Options

- **小型神經網路模型**：長句的前後文理解較好，但檔案大、較慢、在輸入法 DLL 裡執行風險高，而且輸出較難寫成穩定的測試。沒有排除，只是不放進第一版。

## Consequences

- 第一版的詞庫與語言模型取自新酷音 libchewing-data 的 v4 資料，建置工具固定使用某一個版本。程式碼維持 MIT 授權，資料做成獨立的資料檔，沿用上游授權並註明出處。
- 第一版資料檔的大小上限放寬到 50 至 100 MB，實測後再決定是否刪減少見的詞組搭配。
- 準確率測試的句子取自 MozTW cc0-sentences（CC0），不與語言模型的訓練資料重疊。
